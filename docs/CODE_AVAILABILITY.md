# Draft code availability statement

The analysis code supporting this study is available at
[https://github.com/SIJIEJI/NanoHELDI-Pain](https://github.com/SIJIEJI/NanoHELDI-Pain).
The repository contains participant-grouped machine-learning workflows, fold-local
preprocessing, model-evaluation scripts, synthetic tests, and software-environment
specifications. Participant-level mass-spectrometry and clinical data are not publicly
included because they may contain potentially identifying longitudinal information.
Access to eligible deidentified data is subject to institutional approval and the terms
described in the manuscript's Data availability statement.

Before manuscript submission, confirm the data-access wording with the responsible
institution and add the permanent release DOI if one is created.
